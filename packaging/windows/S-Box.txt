Vault Lab S-Box для Windows x64

MSI устанавливает программу и криптоплагин в %LOCALAPPDATA%\Programs\VaultLab
и добавляет пункт S-Box в левую панель Проводника и команды контекстного меню.

Чтобы создать первый файл, откройте нужную папку и щёлкните правой кнопкой
по пустому месту. В Windows 11 откройте «Показать дополнительные параметры».
Выберите «Создать контейнер S-Box», введите имя, например Работа, сохраните
показанный ключ отдельно и вставьте его в консоль для подтверждения.
В этой папке появится Работа.sbox с квотой 1 ГБ.

1. Щёлкните правой кнопкой по локальному контейнеру .sbox. В Windows 11
   выберите «Показать дополнительные параметры», затем «Монтировать S-Box».
2. Введите ключ контейнера (64 шестнадцатеричных символа). Оставьте окно
   провайдера открытым и работайте с файлами в открывшейся папке NTFS.
   Чтобы снова открыть папку, нажмите S-Box слева в Проводнике и дважды
   щёлкните ярлык с именем смонтированного контейнера. Сохраняйте файлы
   внутри открывшейся папки. После завершения копирования или сохранения
   провайдер шифрует каждый закрытый файл целиком в фоне.
3. Сохраните и закройте документы. Выберите «Размонтировать S-Box» на
   исходном контейнере. Перед переносом контейнера дождитесь сообщения
   «Контейнер сохранён и размонтирован.».

В PowerShell провайдер запускается следующей командой.

& "$env:LOCALAPPDATA\Programs\VaultLab\vault-lab.exe" mount 'D:\Архивы\Работа.sbox'

Для закрытия выполните во втором окне PowerShell следующую команду.

& "$env:LOCALAPPDATA\Programs\VaultLab\vault-lab.exe" unmount 'D:\Архивы\Работа.sbox'

Требуются Cloud Files API и локальный профиль на NTFS. Windows может сохранять
расшифрованные данные в рабочей папке и кэше. При требованиях шифрования
физического носителя используйте защиту тома профиля. При сбое оставьте
контейнер по прежнему пути и сохраните %LOCALAPPDATA%\VaultLab\sessions.
Снова подключите его из того же профиля и повторите размонтирование.

Перед обновлением или удалением закройте рабочие сеансы. Для удаления
выберите «Vault Lab S-Box» в списке установленных приложений Windows.

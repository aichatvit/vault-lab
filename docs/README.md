# Документация vault-lab 0.1.0

Документы описывают утилиту Linux с форматом `VLAGOST2` и проект Windows
SD-Reader. Основная инструкция установки и запуска — [корневой README](../README.md).

| Документ | Содержание |
|---|---|
| [Архитектура](ARCHITECTURE.md) | Компоненты, потоки данных, карта исходников |
| [Алгоритмы](ALGORITHMS.md) | Проверка блоков, распаковка, фиксация, упаковка и восстановление |
| [Ключевая схема](KEY_MANAGEMENT.md) | Master, KDF_TREE, разделение ключей, ID/IV, жизненный цикл |
| [Формат данных](DATA_FORMAT.md) | Раскладка контейнера и рабочей папки, квоты в МБ и ГБ |
| [Формат S-BOX и Windows SD-Reader](SBOX_WINDOWS_READER.md) | Общий сценарий Linux и Windows, рабочая папка и упаковка при закрытии |
| [FUSE и процессы](FUSE.md) | Режимы open/mount, callbacks, права, ошибки, сигналы |
| [Модель угроз](SECURITY.md) | Доверие, атаки, защита путей и остаточные риски |
| [Справочник команд](CLI.md) | CLI и консольный клиент |
| [Эксплуатация](OPERATIONS.md) | Установка, backup, восстановление, диагностика |
| [Разработка](DEVELOPMENT.md) | Зависимости, сборка, правила изменений и выпуск |
| [Тестирование](TESTING.md) | Матрица тестов, VM-сценарий, непроверенные случаи |
| [Проектные решения](DESIGN_DECISIONS.md) | Компромиссы, сложность алгоритмов, направления развития |
| [Отчёт упаковки](../PACKAGING_REPORT.md) | Исторические результаты архивной поставки |
| [Исторический отчёт](../TEST_REPORT.md) | Проверка от 2026-11-13 |

Рекомендуемый порядок: README → архитектура → ключевая схема → алгоритмы →
формат → модель угроз. Для запуска достаточно README и руководства эксплуатации.
Диаграммы записаны в Mermaid; исходный текст остаётся читаемым без рендерера.

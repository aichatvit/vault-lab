# Справочник команд

Команды выполняются из корня распакованного проекта после `cargo build --locked`.
Синтаксис: `./target/debug/vault-lab [--plugin PATH] COMMAND`.
Глобальный параметр `--plugin` по умолчанию равен `lib/libaldcrypto.so`.
Для справки: `./target/debug/vault-lab --help` и `COMMAND --help`.

| Команда | Действие |
|---|---|
| `keygen` | Вывод случайного ключа: 64 hex-символа; плагин не требуется |
| `init FILE [--quota-mb N | --quota-gb N]` | Создание нового контейнера с заданной квотой. По умолчанию 1 ГБ |
| `check FILE` | Проверка индекса и блоков упакованного контейнера. Вывод занятости и квоты |
| `open FILE` | Распаковка в зашифрованную рабочую папку, приватное монтирование и консольный клиент. Нужен root |
| `mount FILE MOUNTPOINT` | Распаковка и монтирование в существующий пустой каталог. Упаковка после размонтирования. Нужен root |

Все операции с хранилищем запрашивают ключ в терминале без отображения ввода.
Ключ не является паролем, восстановление отсутствует. Передать его аргументом нельзя.
`init` создаёт файл и сохраняет существующие файлы. Квота — положительное
целое число МБ или ГБ. 1 МБ = 1 000 000 байт, 1 ГБ = 1 000 МБ. При успехе
процесс возвращает 0, при ошибке — 1 с сообщением `Error:` в stderr.

## Замеры без криптоплагина

Глобальный флаг `--benchmark-xor` доступен для `init`, `check`, `open` и
`mount`. Он включает тестовый формат `VLAXOR01` с фиксированным ключом
и пропускает загрузку плагина и запрос ключа. Используйте флаг только для
синтетических данных. [Пример замера](SBOX_WINDOWS_READER.md#разбор-затрат-записи)

## Флаги open для лабораторной проверки

| Флаг | Действие |
|---|---|
| `--test` | Запуск встроенного теста с записью `probe-persistent` |
| `--verify` | Проверка сохранённого тестового файла; несовместим с `--test` |
| `--attack` | Подмена точки bind mount в сценарии; требует `--test` |

Эти сценарии запускайте в отдельном тестовом хранилище. Скрытая команда
`probe` служебная: её запускает служба с открытым дескриптором.

## Консоль внутри open

| Команда | Действие |
|---|---|
| `mkdir PATH` | Создать каталог |
| `put PATH TEXT` | Записать текст в файл |
| `get PATH` | Вывести содержимое файла в терминал |
| `ls [PATH]` | Показать каталог |
| `mv PATH NEWPATH` | Переместить или переименовать файл или каталог |
| `rm PATH` | Удалить файл |
| `rmdir PATH` | Удалить пустой каталог |
| `exit` | Завершить клиент, упаковать изменения и закрыть сессию |

Имена путей в клиенте — UTF-8 без пробелов. Терминал и его история вывода
не защищены шифрованием хранилища. Пример полного запуска — в [README](../README.md#запуск).

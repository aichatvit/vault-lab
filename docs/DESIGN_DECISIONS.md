# Проектные решения и ограничения

| Решение | Практическое следствие |
|---|---|
| Единственный переносимый файл | Закрытый контейнер копируется отдельно от рабочего состояния |
| Индекс и отдельные записи файлов | Дерево хранится в памяти, содержимое обрабатывается блоками до 1 МБ |
| Одинаковая раскладка зашифрованных блоков | Распаковка и упаковка проверяют и копируют содержимое без повторного шифрования |
| Дописывание рабочих блоков | Изменённые записи дописываются. Зашифрованный индекс связывает логические блоки с их смещениями |
| Уплотнение рабочего файла | Актуальные записи периодически переходят в новое поколение. Старое удаляется после фиксации индекса |
| Атомарная замена при закрытии | Для новой упаковки требуется место до замены предыдущего файла |
| Отдельный файл блокировки | Блокировка сохраняется при атомарной замене контейнера |
| CBC и HMAC с разными ключами | Плагин проверяет аутентичность записи до расшифровки |

Упаковка и распаковка требуют последовательного прохода по данным. Во время
записи объём памяти зависит от индекса, размера блока и размера запроса.
Фиксация каждой операции синхронизирует рабочие метаданные. Скорость больших
последовательных записей зависит от плагина, файловой системы и частоты уплотнения. [Алгоритмы работы](ALGORITHMS.md) · [Формат данных](DATA_FORMAT.md)
